# simple-Age-verification-system-
this is a simple age verification system in which user will enter their birth year and if the birth year is Greater or equal to the 2000 then the output will print as you are Verified otherwise it will show you are not 🚫 verified....... this is made by using simple c programming language 🦾

🛡️ Age Verification System in C
A simple and lightweight C program designed to verify a user's status based on their birth year.
🚀 Features
Simple & Fast: Built using pure C language for maximum speed and efficiency.
Instant Logic: Checks if the user's birth year is 2000 or later (\ge 2000).
Clear Feedback: Displays immediate status with visual indicators:
You are Verified ✅ (for birth year \ge 2000)
You are not 🚫 verified (for birth year < 2000)
💻 Code Snippet
Here is the standard implementation for your main.c file:


#include <stdio.h>
void main(){
int A;

printf("What is your  birth year --- ");
scanf("%d", &A);
if (A<=2008 & A>=2000){printf("You are verified !");
}else{ 

printf("YOU ARE NOT VERIFIED");
}
 }
